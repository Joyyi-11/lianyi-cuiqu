# 萃取（lianyi-cuiqu）

从外部优秀经验（Skill、提示词、规则文档、文章、工作流、产品方法）中萃取精华，吸收内化进自己的能力框架，持续打磨、提升自己。最终框架必须同时来自用户自己的目标、实践经验、来源中的有效结构，以及用户主动补充的新方法——来源只提供质量参照、可能性和经验，不是标准答案。

本文件只作面向人的定位与目录说明。六种处理决定、工作流顺序、角色边界与裁决优先级的唯一真实源在 `SKILL.md`，此处不复述——两处各存一份，改动时必然漂移。

## 定位

- 方向：**外部经验 → 自己的框架**（内化）。
- 与 `lianyi-chendian`（自己的实践 → 可复用 skill，外化）方向相反。
- 以用户自己的问题为判断主体，不对每项内容照搬。

